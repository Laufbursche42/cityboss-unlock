Verbindung

Alle Geräte zeigen (wenn deins nicht auftaucht)

CITYBOSS prüft jedes Schreib-Frame mit dem Code aus der Original-App - gib deinen 6-stelligen Code hier ein (intern zählen die letzten 4 Ziffern). Wurde nie ein Code gesetzt, ist er oft 0. Ohne richtigen Code lehnt der Scooter Schreib-Kommandos ab.

Web Bluetooth geht auf dem iPhone nur über die App Bluefy, auf Android oder Desktop über Chrome bzw. Edge. Beim ersten Mal fragt das System nach der Kopplung.

Warte auf Daten vom Scooter. Jede Kachel erscheint, sobald ihr Wert zum ersten Mal ankommt.

Die Live-Werte kommen direkt vom Scooter. Nicht jedes Modell liefert jedes Feld. Welche Register ein konkretes Modell nutzt, ist nicht für alle Modelle bewiesen. Die rohen Meldungen stehen als Hex im Log.

Einstellungen

Tempo und Freischaltung

Register 0xEF/0xF0/0xF1 setzen das Limit für Fahrmodus 1 (Stufe-1, modusabhängig). Register 0xF3 ist Stufe 3 mit der Skalierung Wert = km/h * 1000 + 5000 (aus der App-Analyse). Die Seite hat keine eigene Grenze.
